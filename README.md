# phonelookup（電話番号しらべ）

電話番号を入力すると、その番号の種別と、固定電話なら市外局番の地域を表示する小さなWebツールです。

## できること

- 番号の種別判定：携帯電話（070/080/090）、IP電話（050）、フリーダイヤル（0120/0800）、ナビダイヤル（0570）、020番号、0180/0990の特殊番号帯、固定電話
- 固定電話の市外局番から地域を表示（主な市外局番 約60件を収録）
- ハイフン・スペース・全角数字・+81形式の入力を自動で整える
- その番号をWeb検索するためのリンク（Google / Bing）を表示
- 通話料がかかる番号帯（0570など）には注意書きを表示

## できないこと

個人の電話番号について、契約者の名前や住所を調べられる公式のデータベースは存在しません。このツールが表示するのは「番号そのものの情報」だけです。

入力した番号は保存しません。

## 技術

- Python / Flask の単一ファイルアプリ（app.py）
- テスト: `python -m pytest tests/ -q`
- 起動: `gunicorn app:app`（Render想定）

## 注意

- 携帯電話は番号ポータビリティ（MNP）により、番号から現在の契約キャリアは分かりません。
- 市外局番の地域は目安です。同じ市外局番でも複数の市区町村にまたがります。
